# Privacy

Cart Reset by HyperWumpus has no backend, analytics, or tracking.

Clicking the extension grants temporary access to the current tab through Chrome's activeTab permission. The extension only operates on the Walmart cart URL and Costco Same-Day store pages with the cart drawer open. It reads displayed product names, links, thumbnails, and cart controls to show the review panel and perform user-confirmed actions.

Images load from Walmart's or Instacart's image service, as they do on the shopping site. Cart actions use the retailer's existing controls and signed-in session. Login and payment information are not collected or exported.

Group choices exist in memory while the panel remains open. Downloads contain grouped product names, thumbnail URLs, available links, and Costco quantities and are stored wherever the user saves them. There is no automatic cloud upload.

Closing the panel removes its in-memory state. This extension does not save retailer passwords, place orders, or run unattended cart changes.
